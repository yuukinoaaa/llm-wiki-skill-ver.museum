# llm-wiki-skill

A Claude Code skill and Python helper toolkit for turning local documents into an interconnected Quartz wiki.

The current workflow is document-ingestion first:

1. Extract local `DOCX`, `PDF`, `MD`, or `TXT` files into normalized text blocks.
2. Ask Claude Code to turn those blocks into an ingestion plan.
3. Let Claude Code add marked web enrichments from authoritative sources when useful.
4. Materialize the plan into Quartz Markdown pages with route links, entity backlinks, and Quartz callouts for web enrichments.
5. Validate wikilinks, metadata, and structured web source records.
6. Build HTML with Quartz.

Chinese is the primary documentation language for this project. See [README.zh.md](./README.zh.md) for installation, usage, configuration, business logic, and maintenance notes.

The materializer does not create placeholder pages. Every `outgoing_links` target must be a real page in the plan or existing wiki content. Use `clean-stubs` to remove placeholder pages generated by older versions.

Translation is disabled by default. Use `translate_wiki.py` only when explicitly configured with a local API key.

Web enrichment is enabled in the default workflow, but the helper scripts do not search the web. Claude Code performs research using entity/book/concept names only, records sources in `web_enrichments`, and the materializer renders them as marked “联网补充” callouts. Allowed source types are `museum`, `library`, `university`, `government`, `encyclopedia`, and `publisher`.

## Commands

```bash
python ingest_wiki.py extract path/to/your-real-source.docx --out source.blocks.json
python ingest_wiki.py materialize ingest-plan.json --wiki wiki --dry-run
python ingest_wiki.py materialize ingest-plan.json --wiki wiki --apply
python ingest_wiki.py clean-stubs --wiki wiki --dry-run
python ingest_wiki.py validate --wiki wiki
python ingest_wiki.py serve --wiki wiki --port 8888
```

`source.docx` in examples is a placeholder. Replace it with an existing local file path.
Use `serve` for local preview after `npx quartz build`; plain `python -m http.server` does not resolve Quartz clean URLs to `.html` files.

Run commands from the repository root. If your shell is already inside `wiki/`, use `python ..\ingest_wiki.py serve --wiki . --port 8888`. Local `wiki/ingest_wiki.py` wrappers, `.claude/`, and `tests/` are ignored and are not pushed to GitHub.
